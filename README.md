# خادم تحديث تطبيق مراكز تحفيظ القرآن

مستودع خفيف يخدم غرضاً واحداً: إخبار التطبيق بوجود إصدار أحدث وأين يجده.

## كيف يعمل

التطبيق يقرأ عند الإقلاع:

```
https://raw.githubusercontent.com/Zarax34/felthah-update/main/manifest.json
```

ويقارن `versionCode` بإصداره. إن كان أحدث، نزّل الحزمة من `apkUrl`،
وتحقّق من `sha256`، ثم فتح مثبّت النظام.

**الحزمة لا تُحفظ في هذا المستودع.** تُرفع أصلَ إصدار (Release asset):

- حزمة بـ ٧٠ ميغابايت في كل إصدار تُضخّم تاريخ git بلا رجعة — ولا يمكن
  التراجع عن ذلك إلا بإعادة كتابة التاريخ.
- أصول الإصدارات تدعم طلبات `Range`، وعليها يقوم استئناف التنزيل.

## نشر إصدار

```bash
./release.sh <مسار الحزمة> <versionCode> <versionName> ["ملاحظات"] [--mandatory]
```

مثال:

```bash
./release.sh ~/app-release.apk 2 1.0.1 "إصلاح الإشعارات وتسريع التقارير"
```

السكربت يحسب البصمة والحجم، يرفع الحزمة، ثم يحدّث البيان ويدفعه —
**بهذا الترتيب**: بيان يشير إلى حزمة لم تُرفع بعد يعني تطبيقات تطارد
رابطاً ميتاً.

يتطلّب [`gh`](https://cli.github.com) مسجَّل الدخول.

## حقول البيان

| الحقل | المعنى |
|---|---|
| `versionCode` | عدد صحيح يتزايد. هو وحده ما يُقارَن |
| `versionName` | يُعرض للمستخدم فقط |
| `apkUrl` | رابط الحزمة. **https إلزامي** — التطبيق يرفض غيره |
| `sha256` | بصمة الحزمة. عدم تطابقها يمنع التثبيت |
| `sizeBytes` | لشريط التقدّم وللتحقّق من اكتمال التنزيل |
| `mandatory` | `true` يمنع تأجيل التحديث |
| `releaseNotes` | نصّ عربي يظهر في ورقة التحديث |

## لماذا البصمة إلزامية

الحزمة تُثبَّت بصلاحيات التطبيق. بايتات وصلت من الشبكة دون إثبات أنها
ما نشرتَه أنت هي بالضبط ما يحوّل محدّثاً إلى ناقل برمجيات خبيثة. التطبيق
يرفض أي حزمة لا تطابق بصمتها ولو اكتمل تنزيلها.

## التراجع عن إصدار

أعد `manifest.json` إلى `versionCode` الأقدم وادفع. الأجهزة التي لم
تحدّث بعد تتوقّف، والتي حدّثت لا تتراجع تلقائياً — أندرويد يمنع تنزيل
إصدار أقدم فوق أحدث.
